# QuickBite (Expo)

A starter folder structure for a mobile app UI built with Expo and JavaScript.

## Quick start

1. Install dependencies: `npm install` or `yarn`
2. Start the dev server: `npm start` or `expo start`
3. Run on device/emulator using Expo Go or an emulator

## Structure

- `App.js` - app entry
- `src/` - app source files (components, screens, navigation)
- `assets/` - images and fonts

Preview the Welcome screen (Onboarding):
